What it does

  • Splits two URLs into scheme, host and port and says whether they are same-origin, same-site or cross-site, with the Sec-Fetch-Site value a request between them would carry.
  • Finds the registrable domain with the Public Suffix List, including wildcard and exception rules, and shows which rule matched.
  • Shows when only the scheme or port differs (same-site but cross-origin).

How far to trust it

  • The registrable-domain step agrees with the Python tld package on 120,000 generated hostnames, with and without private domains. It uses the same list data, so it tests the matching, not the list. The list is the 2026-03-06 copy bundled with that package. The origin and site rules follow the web.dev article on same-site and same-origin.
